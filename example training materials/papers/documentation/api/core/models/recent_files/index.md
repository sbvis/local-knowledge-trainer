# Recent Files

The classes below are used to store, present, and filter recent files. [`mv::util::RecentFile`](https://manivault.readthedocs.io/en/latest/api/core/util/file/recent_file.html#_CPPv4N2mv4util10RecentFileE "mv::util::RecentFile") records metadata such as when a file was last opened, enabling the construction of curated lists of recently accessed projects. The same mechanism can also be used for other file types.

- [AbstractRecentFilesModel](https://manivault.readthedocs.io/en/latest/api/core/models/recent_files/abstract_recent_files_model.html)
- [RecentFilesListModel](https://manivault.readthedocs.io/en/latest/api/core/models/recent_files/recent_files_list_model.html)
- [RecentFilesFilterModel](https://manivault.readthedocs.io/en/latest/api/core/models/recent_files/recent_files_filter_model.html)
