# Tasks

A [`mv::Task`](https://manivault.readthedocs.io/en/latest/api/core/task/task.html#_CPPv4N2mv4TaskE "mv::Task") is used to report the progress of a (lengthy) operation, and its lifetime is tracked by the **core** using the models below.

- [AbstractTasksModel](https://manivault.readthedocs.io/en/latest/api/core/models/tasks/abstract_tasks_model.html)
- [TasksTreeModel](https://manivault.readthedocs.io/en/latest/api/core/models/tasks/tasks_tree_model.html)
- [TasksListModel](https://manivault.readthedocs.io/en/latest/api/core/models/tasks/tasks_list_model.html)
- [TasksFilterModel](https://manivault.readthedocs.io/en/latest/api/core/models/tasks/tasks_filter_model.html)
