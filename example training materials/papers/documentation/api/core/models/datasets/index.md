# Datasets

Datasets are stored in the [`mv::AbstractDataManager`](https://manivault.readthedocs.io/en/latest/api/core/managers/abstract_data_manager.html#_CPPv4N2mv19AbstractDataManagerE "mv::AbstractDataManager") and their lifetime is tracked by the model classes below.

Note

This API is **stable** and intended for use by **core developers**. Plugin developers typically do not need to interact with it directly, as it is fully wrapped by the [`mv::AbstractDataManager`](https://manivault.readthedocs.io/en/latest/api/core/managers/abstract_data_manager.html#_CPPv4N2mv19AbstractDataManagerE "mv::AbstractDataManager").

- [AbstractDatasetsModel](https://manivault.readthedocs.io/en/latest/api/core/models/datasets/abstract_datasets_model.html)
- [DatasetsListModel](https://manivault.readthedocs.io/en/latest/api/core/models/datasets/datasets_list_model.html)
- [DatasetsFilterModel](https://manivault.readthedocs.io/en/latest/api/core/models/datasets/datasets_filter_model.html)
