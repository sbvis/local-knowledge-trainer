# Color Schemes

Color schemes alter the look-and-feel of **ManiVault Studio**. Color schemes can be added, removed and altered from the GUI. The classes below are used to store, present and filter color schemes.

Note

This API is **stable** and intended for use by **core developers**. Plugin developers typically do not need to interact with it directly, as it is fully wrapped by the [`mv::AbstractThemeManager`](https://manivault.readthedocs.io/en/latest/api/core/managers/abstract_theme_manager.html#_CPPv4N2mv20AbstractThemeManagerE "mv::AbstractThemeManager").

- [AbstractColorSchemesModel](https://manivault.readthedocs.io/en/latest/api/core/models/color_schemes/abstract_color_schemes_model.html)
- [ColorSchemesListModel](https://manivault.readthedocs.io/en/latest/api/core/models/color_schemes/color_schemes_list_model.html)
- [ColorSchemesFilterModel](https://manivault.readthedocs.io/en/latest/api/core/models/color_schemes/color_schemes_filter_model.html)
