# Context

Context types connect jobs to operation-specific data and framework runtime state. Execution contexts form a hierarchy and share root state, while context payloads carry inputs and intermediate values for a particular operation.

For ownership and synchronization guidance, see [Execution context and shared state](https://manivault.readthedocs.io/en/latest/development/workflows/execution_context.html).
