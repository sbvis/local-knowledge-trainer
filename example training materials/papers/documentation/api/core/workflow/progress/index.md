# Progress

Progress types represent the execution hierarchy independently of diagnostic reporting. Nodes aggregate weighted child progress and retain terminal state; notifiers and presentation utilities can observe the resulting tree.

For progress and cancellation semantics, see [Progress and cancellation](https://manivault.readthedocs.io/en/latest/development/workflows/progress_and_cancellation.html).
